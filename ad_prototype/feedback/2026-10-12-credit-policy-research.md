# 홍보잇다 크레딧·구독 정책 조사 메모

조회일: 2026-10-12 KST. 공식 도움말을 기준으로 조사했다. 이번 주 점검은 화면·버튼 흐름을 보는 UI/UX 검토이며, 요금·크레딧은 실제 원가 확인 전 아이디어 수준의 가안이다. 코드에 차감·재생성·결제를 적용하지 않는다.

## 1. 사용자 선택으로 정리한 현재 방향

- 기존 홈의 ‘홍보물 만들기’를 유지한다. 별도 소개 화면이나 하단 중복 버튼을 추가하지 않는다.
- 이용 유형과 관계없이 로그인 없이 홈에서 제작을 체험한다. 실제 결제를 진행할 때 인증하는 방향이며 결제·인증 연동은 향후 작업이다.
- 하단 4개 메뉴는 서비스 화면에만 표시한다. 채널 선택은 현재 제작 흐름 안에서 유지한다.
- 읽어주기는 현행 페이지 안내·문구 결과 원문 범위를 유지한다.
- 이번 주 교수님 점검은 UI/UX만이다. 실제 AI 생성·결제 완성은 이번 점검 완료 조건이 아니다.
- 구독 월 9,900원/15,000크레딧, 미사용 구독 지급분은 1개월 후 소멸이라는 아이디어를 보존한다.
- 충전 상품 8,900원/10,000크레딧, 4,900원/5,000크레딧, 1,990원/2,000크레딧이라는 아이디어를 보존한다. 충전 크레딧은 무기한, 구독 잔액부터 사용한다.
- 실패·취소 시 차감하지 않는 방향이다. 실행 전 예약했다면 실패·취소 시 해제하는 처리는 향후 기술 설계다.
- 무료 제공량은 영상 1회·포스터 3회·문구 10회, 초기화 없음, 무료 재생성 불가, 소진 시 구독·충전 안내라는 아이디어다.
- 구독 또는 충전 후에는 문구·포스터·영상 모두 유형별 사용량을 차감해 재생성하는 방향이다.
- 문구 100·포스터 200·영상 1,000크레딧도 비교용 임시 후보다. 조사 결과를 근거로 그대로 확정하지 않는다.

현재 다운로드한 파일은 기기에 저장된다. 앱 안 결과 목록은 `useState`로 유지되는 세션 내 기록이며, 새로고침 후 영구 복원을 구현한 상태는 아니다. 로그인 없이 체험한다는 방향과 영구 보관 구현 여부는 따로 기록한다.

| 서비스 | 구독 지급분 | 추가 구매분 | 무료·사용 순서·관련 정책 | 공식 근거 |

### 실패와 마음에 들지 않는 결과의 구분

Runway는 생성 오류로 종료된 작업의 크레딧을 자동 반환한다. 정상 생성 후 프롬프트·외모 등 결과가 기대에 못 미치는 경우에는 자동 반환하지 않는다. 따라서 기술적 실패와 완료된 결과의 품질 불만은 구분해서 운영하는 사례가 있다. 홍보잇다의 현재 선택은 실패·취소 비차감이며, 타사의 품질 불만 처리까지 그대로 채택한 것은 아니다. [Runway 크레딧 반환 안내](https://help.runwayml.com/hc/en-us/articles/34266159290003-Can-I-have-credits-refunded)

### 유형별 차감 차이

타사에서도 유형·모델·길이·해상도별 차감량이 다르다. Luma 예시 표에서 Photon 이미지 1장은 4크레딧(한 번에 4장 생성), Ray2 Flash 720p 5초 영상은 55크레딧, Ray2 720p 5초는 160크레딧이다. Adobe도 영상 등 프리미엄 기능을 별도로 계산한다. 동일 크레딧 수를 모든 서비스의 동일 원가로 비교하지 않는다. [Luma 사용량 표](https://lumalabs.ai/learning-hub/dream-machine-credit-system), [Adobe 기능별 설명](https://helpx.adobe.com/creative-cloud/apps/generative-ai/generative-credits-faq.html)

## 3. 조사에서 얻은 판단

이는 확인한 서비스 세 곳에 대한 비교이며 시장 전체의 통계적 평균이 아니다.

- 구독 지급분의 월별 갱신·소멸과 추가 구매분의 다른 유효기간을 구분하는 사례가 있다. 충전분 무기한은 Runway 사례와 유사하고, Luma는 12개월이라는 차이가 있다.
- 소멸하는 월 지급분을 먼저 사용하는 방식은 Runway·Luma에서 확인된다. 사용자의 ‘구독 먼저’ 방향과 맞는다.
- 무료는 Runway처럼 일회성 제공하는 방식과 Adobe처럼 월 단위 갱신하는 방식이 모두 있다. 무료 초기화 없음은 가능한 한 가지 운영 방식이다.
- 자체 크레딧 충전만으로 재생성을 제공하려는 홍보잇다는 추가 구매를 유료 구독자에게만 제공하는 Runway·Luma의 조건과 차이가 있다. 홍보잇다의 구독·충전 진입 조건은 자체 가안으로 유지한다.
- 실제 공급자의 웹 구독 크레딧과 API 크레딧은 별도일 수 있다. Runway와 Luma는 이를 명시한다. 웹 서비스의 크레딧 숫자로 홍보잇다 API 원가를 바로 계산하지 않는다.

## 4. 영상 1,000·나머지 5에 대한 검토

영상 1,000·문구/이미지 5라면 사용자에게 보이는 차이는 200배다. 실제 원가가 그만큼 다를 수 있는지와 사용자가 제공받는 가치를 별도로 확인해야 하며, 지금 수치만으로 잘못됐다고 확정할 근거는 없다.

비교용 후보는 다음과 같다. 둘 다 확정 정책이나 코드 변경이 아니다.

| 표현 후보 | 문구 | 포스터 | 영상 | 의미 |
|---|---:|---:|---:|---|
| 기존 임시 후보 유지 | 100 | 200 | 1,000 | 영상 1회 = 포스터 5회 = 문구 10회로 설명하기 쉬움 |
| 같은 가치의 단위를 1/10로 축소 | 10 | 20 | 100 | 상대 비율은 같음. 이 안을 택하면 지급 크레딧도 1/10로 함께 바꿔야 기존 가격·사용량과 동일해짐 |

현재는 첫 후보의 비율을 아이디어로 보존하고 실제 모델 비용·출력 품질·결과 가치가 확인된 후 재검토하는 것이 적절하다. 문구와 포스터를 무조건 동일한 5크레딧으로 묶을 이유도 아직 확정되지 않았다. 크레딧은 원가 차이와 사용자가 이해하기 쉬운 가격 구조를 함께 반영해 설계할 수 있다.

## 5. 사용자 추정 원가를 이용한 최소 계산

사용자가 예상한 영상 원가 **1회 약 400원**을 가정한 계산이며 실제 청구서로 확인한 값이 아니다.

- 월 구독 15,000크레딧을 영상에만 사용하고 영상 1회가 1,000이면 최대 15회다.
- 영상 원가 합계 가정: 15×400원 = 6,000원.
- 9,900원과의 차이: 3,900원. 결제 수수료·서버 운영·기타 생성 비용을 반영한 순이익 계산은 아니다.

문구·이미지는 Gemini API 이용 예정이라는 사용자 계획을 기록한다. 실제 비용은 선택 모델, 입력/출력 토큰, 이미지 수·해상도 등에 따라 달라지므로 키를 쓴다는 사실만으로 무료 또는 일정한 저원가라고 확정하지 않는다. 이번 조사에서는 모델을 대신 선택하거나 API를 호출하지 않았다. [Google 공식 API 가격표](https://ai.google.dev/gemini-api/docs/pricing)

## 6. 향후 점검 순서

1. 이번 주에는 화면·버튼 흐름과 가안 안내의 이해도를 검토한다.
2. 생성 기능이 연결되면 영상 모델·길이와 Gemini 문구/이미지 모델을 기록한다.
3. 성공·실패·재생성 작업의 실제 청구량을 수집한다.
4. 유형별 사용량 비율, 구독 지급량, 충전 패키지와 무료 제공량을 재검토한다.
5. 승인된 최종 정책을 기준으로 지갑·인증·차감·제한 UI를 구현한다.

현재 재생성·한도·결제·영구 보관 코드를 변경하지 않았다. 이전 UI 유지보수의 미커밋 변경도 보존했다.
